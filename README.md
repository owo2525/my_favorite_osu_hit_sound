# my_favorite_osu_hit_sound

## This is my favorite osu! hit sound collection!

A collection of my favorite hit sounds for osu!stable.

Feel free to use them in your own osu! skin!

## Installation

1. Open the `sound` folder.
2. Select and copy all files inside (`Ctrl + A` → `Ctrl + C`).
3. Open your favorite osu! skin folder.
4. Paste the files directly into the skin folder (`Ctrl + V`).
5. Replace existing files if prompted.

That's it! Enjoy your new hit sounds!

## Notes

- Designed for **osu!stable**.
- Make sure to paste the files directly into your skin folder, not into a subfolder.
- Some beatmaps may override skin sounds. Enable **"Use skin's sound samples"** in osu! settings if needed.
